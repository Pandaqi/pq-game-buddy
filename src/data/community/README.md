# Community templates

Drop a `.gamebuddy` file here and run `bun run gen`. The gallery picks it up with the
`community` tag, the linter checks it, and it is compiled into the app like every
bundled template.

Naming: kebab-case, one game per file, for example `wingspan-asia.gamebuddy`.

Read `docs/COMMUNITY.md` before opening a pull request. Short version: write the
summary yourself, link the official page, use the tools that already exist, and put
house rules in `[variant <id>]` blocks.
